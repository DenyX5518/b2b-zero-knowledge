# Контур — zero-knowledge B2B/B2G MVP

Интерактивный демонстрационный MVP закрытой корпоративной среды: защищённые чаты, документы, сотрудники, политики, аудит и контур ключей.

## Локальный запуск

Приложение buildless и не требует установки зависимостей:

```powershell
node scripts/serve.mjs
```

Откройте `http://127.0.0.1:4173`. Демо-контур разблокируется одной кнопкой; фраза `demo-2026` показана в интерфейсе и не является секретом.

При занятом порте можно передать другой: `node scripts/serve.mjs 4174`.

## Важно

Это demonstrator, а не production security implementation. Целевая система описана в [ARCHITECTURE.md](ARCHITECTURE.md), осознанные упрощения — в [MVP_LIMITATIONS.md](MVP_LIMITATIONS.md).

Внутри MVP реальные операции WebCrypto AES-256-GCM выполняются в браузере, ключ живёт только в памяти вкладки, а в `localStorage` сохраняется ciphertext. Recovery 2-of-3, серверная авторизация и распределённый audit показаны как продуктовый workflow, но не как готовый криптографический протокол.
